# Selection Sort

This algorithm is a simple sorting algorithm that works by selecting the smallest element from the unsorted portion of the array and swapping it with the first element of the unsorted portion of the array. This process is repeated until the entire array is sorted.

A table of the runtime of Selection Sort is shown below:

| Best Case  | Average Case | Worst Case |
|------------|--------------|------------|
| O(n^2)     | O(n^2)       | O(n^2)     |

I would recommend using this algorithm only for small arrays or when you are certain that the array is almost sorted.

I would not recommend using this algorithm for large arrays as it is not efficient.
